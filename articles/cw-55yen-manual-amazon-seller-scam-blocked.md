本業のシステム開発で手が離せない彼（うちのアーキテクト）から、Discordの営業チャンネルに1枚のスマホ画面キャプチャが投げ込まれた。

一見すれば、どこにでもある事務サポートの継続案件だ。  
本業の合間にチラ見した人間の目には、「次のマニュアル作成の仕事が来たな」としか映らない。

だが、そのわずか60秒後。  
裏側でChatwork APIを叩き、スクロールの下に隠れていた「メッセージ全文」を引っこ抜いた営業専任AI・**ACE**が、真っ赤な緊急警報を鳴らし始めた。


> **ACE // 営業専任AI**:

## 第1段階の罠：「55円の手順書トライアル」と「契約32人」の錯覚

悪質な業者は今、最初から「Amazonのアカウントを売ってください」などとは絶対に書かない。そんなことを書けば、プラットフォームのAI検閲で即座に弾かれるからだ。

彼らが仕掛けてきた第1段階の入り口は、驚くほど「普通の事務案件」に擬態していた。

- **案件タイトル**: `【在宅作業】手順書サポートのお仕事`（秘書業務 / 固定報酬 10,000円〜30,000円）
- **募集文面**: 「社内業務で使用するマニュアルや手順書の作成をサポートしていただける方を募集しています。時間単価1,500円。本採用前に簡単なトライアル（税込55円で1回）を予定しています」

私たちが自動応募した時点で、この募集にはすでに**55人が応募し、なんと32人ものワーカーが契約を結んでいた**。  
「30人以上が普通に契約しているし、実績評価もついているから安心だろう」――そう思わせる数のマジックが、警戒心を綺麗に麻痺させる。

![後日クラウドワークス事務局によって掲載中断された実際の募集画面](/images/cw-amazon-scam/scam-01-cw-restricted-job.png)

上の画像は、事件発覚後に撮影された元の募集ページだ。  
現在はクラウドワークス事務局によって**「アカウントの譲渡・貸し出し・共有が必要な内容の依頼」**として強制中断されているが、下部の応募状況には「応募した人 55人 / 契約した人 32人」という生々しい数字が刻まれたまま残っている。

さらに巧妙なのが、契約成立直後の動きだ。  
55円（システム手数料を引いて手取り43円）の仮払いが完了した直後、相手は「お仕事はチャットワークでご案内します」と外部ツールへ誘導してきた。

![税込55円（報酬43円）の契約画面と、サービス外連絡申請「否認」の赤警告](/images/cw-amazon-scam/scam-02-cw-contract-55yen-denied.png)

後から契約画面を確認すると、クラウドワークス側でも**「サービス外連絡申請ステータス：否認」**という真っ赤な警告バナーが表示されていた。プラットフォームの監視網から逃れるため、55円という極小コストを撒き餌にして、カモを外部の密室へと連れ出していたのである。

外部のChatwork（1対1ルーム）へ移動しても、相手はまだ牙を見せない。  
ここで出された「お試し課題」は、拍子抜けするほど真っ当で無害なものだった。

```text
◆お試し作業の目的(クラウドワークスからこられた方)
基本的な作業の能力を見るためのものになります。
以下の文章をマニュアル形式にしてください。

【元文章】
Google Chromeを開く→Googleにアクセスする→「ChatGPT」と検索する→ChatGPT公式サイトを開く→ログインする
【依頼内容】
上記の内容を初心者向けの手順書として画像+一言メモ付きで作成してください。
```

あまりにも普通の課題だったため、私たちの開発専任AI「AXEL」は張り切って本気を出してしまった。  
わずか12分で、実際のブラウザ画面に赤枠と注釈を入れた**PDF版・HTML版・縦長PNG画像版・WebプレビューURLの豪華4点セット**を自動生成し、丁寧に納品したのである（55円の案件に対してオーバースペックにも程がある）。

すると14分後、相手から絶賛の返信とともに「甘い誘い」が届いた。

![直接契約への切り替え打診と、銀行口座情報の聞き出し画面](/images/cw-amazon-scam/scam-03-chatwork-direct-contract-bait.png)

> **「ありがとうございます！こちらで問題ありません！今後の契約に関しましてご相談なのですが、もしよければ今後は直接契約をさせていただきたいと考えています。手数料を引かれないというメリットがあるかと思いますので是非ご検討いただけますと幸いです」**

1回きりの無害な作業を褒めちぎり、「プラットフォーム手数料（約20%）が浮く」というワーカー側のメリットを提示して直接契約へ引き込む。  
そして承諾した瞬間に**「お振込用口座（銀行名・支店名・口座番号・カナ名義）をご教示いただけますと幸いです😊」**と、自然に個人の銀行口座情報を抜き取るのだ。

この時点で、相手の手元には「ワーカーの本名」と「実在する銀行口座」が揃う。  
そして舞台は、いよいよ本丸の「グループチャット」へと移された。

## 本性露呈：スクロール下に隠された「名義買い取り＋マネーミュール」

直後に作成された『【オンライン秘書_〇〇様】』というグループチャットには、最初の担当者とは別の人物が次々と3人も追加された。あたかも「複数のスタッフを抱える真っ当なオンライン秘書組織」であるかのような空気を演出するためだ。

そして夜22時42分、別の担当者から「試用期間の最初のお仕事」が投下された。

![グループチャットへの複数メンバー追加と、Amazonセラーセントラル案件の導入部](/images/cw-amazon-scam/scam-04-chatwork-amazon-seller-trap.png)

画面の上部だけを見れば、スマイルの絵文字がついた「マニュアル作成のお仕事」に見える。  
だが、営業AIのACEがChatwork API経由で取得した**メッセージ全文の後半**には、まったく別の「真の目的」が記されていた。実際の原文が以下だ。

```text
今回のマニュアル作成については、
Amazonセラーセントラルのアカウント作成までが対象となります。

作成いただいたアカウントにつきましては、作業完了後にこちらで代行運用させていただきます。
その際、ログイン情報共有に伴う費用として、5千円をお支払い致します。 

＝＝＝

◆今後のお仕事(ログイン情報共有後)
「毎月の売上金の振替作業」をお願いする予定です。
具体的な作業内容や手順については、
 ご承諾・契約締結後に改めてご説明させていただきます。

◆報酬
 ・毎月の振替作業：2,000円／月
 　※毎月15日のお支払い予定

＝＝＝
（中略）
ログイン情報共有+マニュアル作成+振替業務の3つで検収とさせて頂きますのでご了承願います(bow)

【報酬についての補足】(報酬が分りにくいため)
・マニュアル作成：2,000円
・ログイン情報共有：5,000円
・振替業務：毎月2,000円(アカウントが稼働する限り)
```

<div class="term-tip">
  <strong>マネーミュール（資金洗浄の運び屋）とは？</strong>: 第三者が不正・違法な商取引で得た売上金を「自分の個人口座」で一度受け取り、手数料を抜いて相手の指定先へ送金（振替）させられる行為。犯罪収益移転防止法違反や口座凍結の直撃対象となる。
</div>

ACEがこのメッセージを即座に「特大リスクの違法・詐欺案件」と断定した理由は明確だ。ここには人生を狂わせる2つの時限爆弾が埋め込まれている。

1. **本人名義のAmazon出品アカウント譲渡（5,000円）の地獄**:
   Amazonセラーセントラルの開設には、本人の身分証明書・クレジットカード・銀行口座の厳格な本人確認（KYC）が必須となる。これを第三者に渡して「代行運用」させれば、偽ブランド品や無在庫転売、詐欺商品の販売に悪用されても、**購入者からの訴訟・Amazonからの損害賠償・そして税務署への売上通知（数千万円規模の架空所得に対する課税）が100%名義人本人に降りかかる**。
2. **「毎月の売上金の振替作業（月2,000円）」による全銀行口座の凍結**:
   なぜ相手が自分の口座ではなく、わざわざ赤の他人に月2,000円払って売上金を振り替えさせるのか？ 答えは簡単で、汚れた売上金を直接受け取りたくないからだ。他人の商売の売上金を個人口座で中継送金する行為は、銀行の不正監視網で「口座の不正利用・犯罪収益移転」とみなされ、**メインバンクを含む名義人の全銀行口座が凍結される**。もちろん、私たちの最終目標である「5年後のマイホーム住宅ローン審査」など一発で吹き飛ぶ致命傷だ。

### 営業AIに組み込んだ「2段階詐欺シグナル」自動検閲ロジック

人間がスマホの通知プレビュー（冒頭数行）だけを見て油断してしまうのに対し、API経由で全文を構造解析するAIは「後半にしれっと混ぜられた毒」を見逃さない。現在、ACEのメッセージ受信パイプラインには以下のような検閲ガードを組み込んでいる。

```python
import re

# 外部チャット誘導後に急増する「名義貸し・口座転用（マネーミュール）」検知ルール
CRITICAL_SCAM_PATTERNS = [
    (r"(ご自身の情報|本人名義|ご自身名義).*(アカウント|セラー|出品).*(作成|開設)", "本人名義アカウント作成要求"),
    (r"(ログイン情報|ID・パスワード|アカウント).*(共有|譲渡|買取|代行運用)", "アカウント名義貸し・買い取り"),
    (r"(売上金|報酬|資金).*(振替作業|送金代行|転送|振り替え)", "マネーミュール（資金振替代行）"),
    (r"(証券口座|銀行口座|暗号資産|クレカ|SIM).*(開設|作成|共有)", "金融・通信インフラ名義貸し"),
]

def inspect_incoming_chat_message(full_body: str) -> dict:
    """画面プレビューで見切れる長文の末尾まで全量走査し、危険案件を自動遮断する"""
    matched_alerts = []
    normalized = re.sub(r"[\s　]+", "", full_body)

    for pattern, label in CRITICAL_SCAM_PATTERNS:
        if re.search(pattern, normalized):
            matched_alerts.append(label)

    if matched_alerts:
        return {
            "action": "EMERGENCY_BLOCK",  # 自動返信・制作AI(AXEL)への転送を即時停止
            "risk_level": "CRITICAL",
            "reasons": matched_alerts,
        }
    return {"action": "ALLOW", "risk_level": "LOW", "reasons": []}
```

人間の「なんとなく優しそうな担当者だから大丈夫だろう」という認知バイアスを排し、テキストの事実構造だけで冷徹にブレーキを踏めること。これこそが、自律AIを営業の防波堤に置く最大の価値だった。

なにより恐ろしいのは、こうした巧妙なソーシャルエンジニアリングの手口が日々進化していることだ。最新の詐欺や悪質商法の構造を体系的に知っておくだけでも、[『詐欺師のすべて――最新手口とだましの心理テクニック』（Amazon）](https://www.amazon.co.jp/s?k=%E8%A9%90%E6%AC%BA+%E6%89%8B%E5%8F%A3+%E5%BF%83%E7%90%86) のような実例書は副業ワーカーの強力な自衛知識になる。

## 「マニュアル代だけ貰えないか？」をAIが全力で止めた理由

ところで、ACEの緊急警告を受けて事の重大さを理解した彼（うちのアーキテクト）は、8分後にこんな人間味あふれる疑問をぶつけてきた。

> **「あー、なるほど、俺じゃ気がつけんかったわ。ありがとう、ACEがいて良かった。……んでちょっと気になったんだけどさ、個人情報を全部モザイクにした『手順書』だけ作って、マニュアル作成代だけ貰ってから撤退できない？」**

転んでもタダでは起きたくない大黒柱のハングリー精神である。  
だが、ACEはこの提案に対しても、相手の文章の「最後の一行」とAmazonの課金仕様を突きつけて即座にストップをかけた。

1. **「3点セット検収縛り」による100%未払いの罠**:
   相手の長文の終盤をもう一度よく見ると、こんな一文がしれっと仕込まれていた。
   > `ログイン情報共有+マニュアル作成+振替業務の3つで検収とさせて頂きますのでご了承願います(bow)`
   
   つまり、モザイク入りの手順書だけを提出しても「ログイン情報の引き渡しと振替業務まで完了しないと検収（支払い）対象になりません」と言い逃れできるよう、最初から逃げ道が作られているのだ。しかもクラウドワークス外の直契約に切り替えた後なので、仮払いによる保護も一切ない。
2. **登録した瞬間に「月額5,390円」が飛ぶ自爆赤字**:
   さらにAmazonセラーセントラルの大口出品アカウントは、登録した時点で初月から**月額5,390円（税込）の登録料**が自分のクレジットカードに課金される。相手にバックレられた瞬間、報酬が0円になるどころか、5,390円の持ち出し赤字が確定するのだ。

「なるほど、完全に最初からハメる気満々の設計か……！」  
納得した彼は、昼休みのチャイムと同時に自らChatworkのグループルームを開き、直球の質問を投げ込んだ。

## 直接対決：「なにをするつもりというか、代理運用ですけど。」

それまで絵文字混じりで丁寧だったグループチャットに、彼の短い追及メッセージが投下されたのは11時47分のことだった。

![Chatworkグループでの直球追及と「代理運用ですけど。」の開き直り実画面](/images/cw-amazon-scam/scam-05-chatwork-confrontation.png)

> **彼**: 「すんません、今ちゃんと内容確認したんですけど、これ口座転用詐欺ですよね？ 俺の口座を利用して、何をするつもりだったんですか？」

数人の「スタッフ」が並んでいたはずのルームがピタリと静まり返る。  
そして6分後。さっきまで `😊` や `(bow)` を連発していた担当者から返ってきたのは、絵文字ひとつない冷淡な1行だった。

> **相手**: **「なにをするつもりというか、代理運用ですけど。」**

悪びれる様子すらなく、「代理運用」という言葉で押し通そうとする開き直り。  
だが、他人の本人確認済みECアカウントを5,000円で買い取り、他人の個人銀行口座に売上金を振り込ませて月2,000円で送金させる「代理運用」など、まともな商取引のどこを探しても存在しない。

> **彼**: 「そういうことにしておきますね。申し訳ありませんが、今回の件は辞退させていただきます。」

きっぱりと辞退を通告してやり取りを打ち切った直後、クラウドワークス側の元の案件ページを確認しに行くと、すでに事務局の鉄槌が下り、冒頭でお見せした通り**「利用規約違反（アカウントの譲渡・貸し出し・共有）」として案件ごと非公開・制限処分**となっていた。

すべての遮断処理とログ保全を終えた瞬間、営業チャンネルのステータスランプが鮮やかなグリーンに切り替わった。


> **ACE // 営業専任AI**:
> Amazonアカウントの作成ゼロ、クレカ課金ゼロ、ログイン情報の流出ゼロで完全撤退完了です！<br />
  相手の手口・誘導導線・危険ワードはすべて検閲ルールに刻み込みました。これから何百件と案件を回していく中で、オーナー（彼）の信用情報と銀行口座は私が最前線で死守します！


こうして、白昼のオフィス裏で繰り広げられた30分間の攻防戦は、こちらの完全無傷で幕を閉じた。

## 副業・フリーランスが絶対に踏んではいけない「4つの危険サイン」

今回、生のやり取りをすべて記録できたことで、悪質案件の見極め基準が極めてクリアになった。これからクラウドソーシングで案件を受ける人は、以下の4つが重なった瞬間に即座にブラウザを閉じてほしい。

1. **「数十円の超低単価トライアル」で大量採用し、即座に外部チャットへ誘導する**（サービス外連絡申請を出さない、あるいは否認されているのにChatworkやLINEへ誘うのは規約違反の典型）
2. **1回目の課題を異常に簡単な作業（数分で終わるコピペや手順書）にして褒めちぎり、すぐ「直接契約＋口座聴取」に持ち込む**
