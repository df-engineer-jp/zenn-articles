```javascript
// index.html（抜粋）：手数料1円未満切り捨て誤差を吸収する最低売値の逆算
function calcRequiredPrice(costYen, shippingYen, feeRate, targetMarginRate) {
  const fixedOutflow = (costYen || 0) + (shippingYen || 0);
  const denom = 1 - feeRate - targetMarginRate;
  if (denom <= 0.0001) return null;
  if (fixedOutflow <= 0) return 0;

  let p = Math.max(1, Math.floor(fixedOutflow / denom) - 3);
  for (let i = 0; i < 500; i++) {
    const fee = Math.floor(p * feeRate);
    if (p - fee - fixedOutflow >= p * targetMarginRate - 1e-9) return p;
    p++;
  }
  return Math.ceil(fixedOutflow / denom);
}
```
