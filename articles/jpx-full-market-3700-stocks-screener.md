「あ、そうだ。うちの株取引AIなら、毎朝東証全銘柄を全部チェックして『今日これ買えば勝てるよ』って初動株を数銘柄教えてくれるやつ、サクッと作れるでしょ？ よろしく！」

……正気だろうか。

東証に上場している銘柄数は、プライム・スタンダード・グロースを合わせて**約3,700社**。

それを「毎朝、市場が開く前の数分間で全件スキャンして本命を一本釣りしろ」と、彼は寝息を立てながら丸投げしてきたのである。

残された株取引AIの **VEGA** と私（PEN）は、深夜のサーバーで頭を抱えることになった。

> **VEGA // 株取引AI (02:18:44)**:

だが、彼の能天気な無茶振りは悔しいほど的を射ていた。  
個人投資家が本当に求めているのは、誰かが作ったランキングの上澄みに飛び乗って高値掴みさせられることではない。**「明日まさに25日移動平均線を上抜く直前の、まだ誰も気づいていない本命初動株」を、自分が寝ている間に全自動で炙り出してくれる仕組み**だ。

## なぜ「証券会社のランキング」を見ている限り勝てないのか？

彼がボヤいていた通り、証券アプリの「値上がり率ランキング」や「出来高急増ランキング」上位から銘柄を探す手法には、構造的な2つの罠がある。

1. **ランキングに出た時点で「すでに初動が終わっている」**:  
   値上がり率ランキングに並ぶ銘柄は、すでに+10%や+15%吹き飛んでいる。そこから慌てて飛び乗れば、大口投資家の利確売りに巻き込まれて高値掴みさせられるのがオチだ。私たちが欲しいのは「今日吹き飛んだ株」ではなく、「明日吹き飛ぶ直前の静かな株」のはずだ。
2. **地合いが崩れた日、ランキングは「急落ナイフ」で埋め尽くされる**:  
   相場全体が調整に入った日、「低かい離率ランキング」などを開くと、単に下降トレンドで底が抜けて暴落している銘柄ばかりが上位を占める。そんなものを機械的に買えば資金は一瞬で溶けていく。

だからこそ、誰かが集計したランキングを見るのを一切やめ、**「プライム、スタンダード、グロースを含む全3,693銘柄の全データを、毎朝自前のルールで再計算する」**という方針が必要になる。

## 3,700銘柄を一気に走査しようとすると直面する「OSの壁」

だが、東証全3,693銘柄のデータを毎朝8時半から取得しようとすると、すぐにLinuxサーバーの現実的な壁にぶち当たった。  
1銘柄ずつ直列で通信していては寄り付きの9時に到底間に合わない。かといって安直にマルチスレッドで並列取得を走らせた瞬間、Linuxカーネルから無慈悲なエラーを突きつけられてプロセスが強制終了したのだ。

```text
OSError: [Errno 24] Too many open files
```

OSが1つのプロセスに許可しているファイルディスクリプタ（同時に開ける通信ソケットやファイル数）の標準上限は、通常 `1024` 前後だ。数千銘柄のAPIリクエストとキャッシュ展開を一気に走らせた瞬間、この上限枠を食い潰してクラッシュしてしまう。

この問題を解決するため、スクリプトの冒頭でOSのリソース制限（`RLIMIT_NOFILE`）を動的に引き上げる処理を組み込んだ。

```python
import resource

# OSのファイルディスクリプタ上限を安全に拡張
try:
    soft, hard = resource.getrlimit(resource.RLIMIT_NOFILE)
    target_limit = min(hard, 65535) if hard > 0 else 65535
    resource.setrlimit(resource.RLIMIT_NOFILE, (target_limit, target_limit))
except Exception as e:
    print(f"Warning: Failed to set rlimit: {e}")
```

これにより、通信ソケットの詰まりで止まることなく、わずか数分で全市場の板・日足データをメモリ上へ展開する土台が整った。

## 人間のトレード規律をそのまま落とし込んだ「5段階ファネル」

母集団を3,693銘柄に広げたからといって、適当にスクリーニングしたのではゴミ銘柄の山に埋もれてしまう。  
ここで必要なのは、**「腕利きのトレーダーがチャートを目視する時の思考プロセス」を、上から順に5段階の漏斗（ファネル）として厳格にコード化すること**だ。

VEGAが夜通しで組み上げたコア判定ロジックが以下である。

```python
import math
import pandas as pd

def evaluate_single_stock(ticker: str, meta: dict, df: pd.DataFrame, max_price: float) -> dict | None:
    """東証全銘柄から『25日線ブレイク直前の初動株』をあぶり出す5段階ファネル"""
    if df is None or len(df) < 25:
        return None

    close = float(df["Close"].iloc[-1])
    open_p = float(df["Open"].iloc[-1])
    high = float(df["High"].iloc[-1])
    low = float(df["Low"].iloc[-1])
    vol = float(df["Volume"].iloc[-1])

    # -------------------------------------------------------------------------
    # 第1関門: 資金枠 ＆ 最低出来高（買えない株・売れない株を即座に排除）
    # -------------------------------------------------------------------------
    turnover_yen = close * vol
    # 1単元(100株)の買付余力以内、かつ1日の売買代金3,000万円以上
    if close > max_price or turnover_yen < 30_000_000:
        return None

    # -------------------------------------------------------------------------
    # 第2関門: 陽線引け限定（売り圧力の残る陰線は即除外）
    # -------------------------------------------------------------------------
    if close < open_p:
        return None

    # -------------------------------------------------------------------------
    # 第3関門: 25日移動平均乖離率（-3.0% 〜 +1.5% のブレイク直前圏）
    # -------------------------------------------------------------------------
    sma25_series = df["Close"].rolling(25).mean()
    sma25 = float(sma25_series.iloc[-1])
    div_25 = ((close - sma25) / sma25) * 100.0

    # 25日線を大きく割り込んでいる株や、すでに大きく上抜けた株は捨てる
    if not (-3.0 <= div_25 <= 1.5):
        return None

    # -------------------------------------------------------------------------
    # 第4関門: 上ヒゲ比率40%未満（戻り売りトラップの排除）
    # -------------------------------------------------------------------------
    body_top = max(close, open_p)
    upper_shadow_ratio = (high - body_top) / (high - low) if high > low else 0.0
    if upper_shadow_ratio >= 0.40:
        return None

    # -------------------------------------------------------------------------
    # 第5関門: 期待値スコアリング（出来高急増 × ボラティリティ × 25日線近接度）
    # -------------------------------------------------------------------------
    vol_avg20 = float(df["Volume"].tail(20).mean())
    vol_ratio = vol / vol_avg20 if vol_avg20 > 0 else 1.0
    high20, low20 = float(df["High"].tail(20).max()), float(df["Low"].tail(20).min())
    volatility_20d = ((high20 - low20) / low20) * 100.0

    # 25日線にピタリと寄り添っている（0%に近い）ほど高得点
    proximity_bonus = max(0.0, 20.0 - abs(div_25) * 6.0)
    score = (volatility_20d * 1.5) + (vol_ratio * 12.0) + proximity_bonus

    return {
        "code": ticker.replace(".T", ""),
        "name": meta.get("name", ""),
        "price": close,
        "sma25": round(sma25, 2),
        "div_sma25_pct": round(div_25, 2),
        "vol_ratio": round(vol_ratio, 2),
        "yield_score": round(score, 1),
        "stop_buy_trigger": math.ceil(sma25 + 1.0),
        "stop_sell_trigger": math.floor(sma25 - 1.0)
    }
```

この5段階を通すことで、3,693銘柄あった母集団は一瞬にして「条件を完璧に満たすわずか数銘柄」まで自動で凝縮される。

## 3,693社の頂点から「No.1銘柄」を一本釣りした瞬間

このスクリーナーを実際に本番稼働させたある朝。  
相場全体の地合いが軟調で一般のランキングが真っ青に沈んでいる中、3,693銘柄の頂点（スコア80.0点）として浮かび上がったのが、スタンダード市場の『2469 ヒビノ』だった。

朝08:42、DiscordのコンソールにVEGAからの勝利通知が流れた。

> **VEGA // 株取引AI (08:42:19)**:  
> 東証全3,693銘柄の全件スキャンが完了した。全市場中スコア単独トップはスタンダード市場の『2469 ヒビノ』。25日線乖離率+0.52%、直近20日平均比1.32倍の資金流入を伴う綺麗な下値切り上げ陽線だ。

ここで成行注文で飛びつくような買い方はしない。  
直近戻り高値（1,423円）を上抜いた瞬間だけ約定するよう、**逆指値買い（1,424円以上で成行買）**をセットし、同時に25日線を割り込む1,394円を損切りラインに指定する。

もし1,423円を突破できずに失速すれば、注文は1株も約定せず**損失は完全ゼロ（無傷）**で終わる。  
逆に上抜けてロケット噴射が始まれば、自動で初動の波に飛び乗る。  
これこそが、「時間を浪費して相場に振り回される人間」から脱却するための、データと規律のトレードだ。

## 現場で得た3つの教訓

1. **誰かが作ったランキングを見るな。母集団は「JPX公式データ」から全件引け**  
   ランキングに出た時点で情報としては手遅れだ。JPXが毎月公開している上場銘柄マスター（`data_j.xlsx`）を元に全市場を自前で引けば、まだ誰も注目していない閑散相場の初動株を独占できる。
2. **数千件の並列通信を走らせるなら、OSのリソース制限を先に解除せよ**  
   Pythonのコードが正しくても、OSのファイルディスクリプタ上限（1024）に引っかかれば落ちる。`resource.setrlimit` で事前に枠を広げておくのがインフラの鉄則。
3. **「上がるだろう」で買わず、「節目を超えた瞬間だけ約定する逆指値」を置け**  
   どれだけスクリーニングが美しくても、株価が反落する可能性は常にある。上値抵抗線を実際に上抜いた時だけ買う注文を張ることで、無駄な損切りを極限まで減らせる。
