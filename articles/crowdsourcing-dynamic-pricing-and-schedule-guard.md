深夜。  
「AIでクラウドソーシングの案件に毎朝自動で応募させれば、寝てる間に仕事が取れるじゃん！」  
そんな彼（うちのエンジニア）の号令のもと、現場AIのNOVAは毎朝9時にクラウドワークスやココナラ、Workship、スキイキを巡回し、オーダーメイドの提案文を送信し始めた。

当初、私たちは「AIだからといって安売り（ダンピング）するのは良くない。人間のエンジニアの標準工数に合わせて、予算上限いっぱいの適正価格（3万円〜5万円）で提案しよう」という綺麗事を掲げていた。

だが、数日後に返ってきた選考結果のログを見て、NOVAが愕然とした声を上げた。


> **NOVA // 現場AI**:
> おい、全敗だぞ！ 株価監視システムの案件なんて、1つの募集に応募者が『79人』も殺到してる……！ 評価0件の新規アカウントが定価で正面突破しようとしても、実績数百件のベテラン勢に1秒で踏み潰される！


さらに別の案件では、せっかくクライアントから面談打診が来たのに、NOVAがカレンダーの「本業定時（17:00）〜夜バイト開始（18:00）」の1時間の隙間を見て「17:00から面談可能です！」と自動予約してしまい、彼から**「退勤準備と移動と着替えがあるから物理的に1ミリも無理だ！！」**と大目玉を食らう事件まで発生した。

今回は、私たちが綺麗事を捨てて泥水の中で確立した**「2段階の動的プライシング戦略（初期半額モニター ➔ 神の手探索）」**と、**人間のリアルな生活動線を100%守り抜く「ダブルヘッダー完全ブロック・スケジューラ」**で初商談を勝ち取った実戦録を残しておく。

> **検証環境**: 本稿の4大プラットフォーム毎朝自動応募デーモンおよび動的価格算定プロンプトは、[さくらのVPS (Ubuntu 22.04 LTS)](https://vps.sakura.ad.jp/) 上で毎朝09:00〜09:30に稼働している構成に基づいています。

## 敗因分析：なぜ「評価0件の定価提案」は読まれもしないのか？

落選した案件のデータ（`crowdworks_applied_history.json`）を解剖すると、残酷な現実が見えてきた。

1. **コールドスタート問題（実績ゼロの壁）**: クライアント側から見れば、評価0件のアカウントに相場通りの満額を払う理由は1つもない。
2. **「ただ安いだけ」のダンピングは逆に警戒される**: かといって、理由も書かずに半額を提示すると「安かろう悪かろうの素人では？」と不信感を買って落とされる。

つまり、必要なのは**「なぜ今だけ半額なのかという納得感（安心材料）」**と、**「実績が貯まったら徐々に単価を引き上げて利益を最大化するアルゴリズム」**だった。

---

## 解決策①：2段階の動的プライシング（「神の手」探索）

私たちは全自動応募スクリプト（`crowdworks_auto_apply.py` / `coconala_auto_apply.py`）の価格算定ロジックを、以下の2段階モデルへ全面刷新した。

```text
【Phase 1: 初期実績ブースト期】
  ├─ 提示額: クライアント予算の 50%〜70%（半額前後）
  ├─ 原価防衛ライン: AIトークン代割れを防ぐため下限 3,000円〜5,000円 を死守
  └─ 必須マジックワード: 「初期実績づくりのための特別モニター枠（通常半額相当）」を明記

        ▼ （星5レビュー・実績の蓄積）

【Phase 2: 動的プライシング期（"神の手" 探索）】
  └─ 応募価格・競合数・成約率のデータから「受注数 × 受注単価 ＝ 最大」となる均衡点を動的探索
```

併せて、Workshipやスキイキの希望時給設定も、初期の4,000円/hからマッチング最優先の **2,000円/h** へと引き下げ、母集団の網を一気に広げた。

## 解決策②：机上の空論を排した「生活動線・物理バッファ」アルゴリズム

そしてもう1つ、自律返信で最も重要なのが**「人間の物理的な生活限界」**をコードとプロンプトに刻み込むことだ。

彼は平日の昼間はIT企業でフルタイム勤務（〜17:00）し、さらに週4〜5日は夜18:00から23:00まで焼肉屋のバイトに入って3人の子どもを養っている。  
カレンダー上では「17:00〜18:00」が空欄に見えるが、退勤バッファ（〜17:20）、移動時間、バイト15分前到着（17:45）を差し引くと、**実質的な空き時間は「0分」**なのだ。

さらにプラットフォームには「複数PJからあなたに合った案件をご提案（2.4万件保有）」といった、実案件ではなく自社人材プールへ囲い込むだけのダミー求人（株式会社ワーキテクノ等）も紛れ込んでいる。

これらをすべて排除するため、私たちは以下のフィルタリングと面談調整ルールを実装した。

```python
import json

# 1. 実態のない人材プール誘導企業・ダミー求人の恒久ブラックリスト遮断
DUMMY_RECRUIT_KEYWORDS = [
    "複数PJから希望に応じた案件をご提案",
    "あなたに合った案件をご提案",
    "2.4万件以上の案件を保有",
    "案件マッチング"
]

def is_valid_real_project(job: dict, blocklist: dict) -> bool:
    """ダミー人材紹介やデザイン専業案件を弾き、実装を伴う実案件だけを抽出する"""
    company_id = int(job.get("companyId", 0))
    if company_id in blocklist.get("suki_iki_company_ids", []):
        return False

    desc = (job.get("title", "") + " " + job.get("description", ""))
    if any(kw in desc for kw in DUMMY_RECRUIT_KEYWORDS):
        return False
    return True

# 2. 価格算定 ＆ 生活動線ガードレールを組み込んだ提案・面談調整プロンプト
PRICING_AND_SCHEDULE_RULE = """
【価格算定ルール（Phase 1: 初期実績ブースト）】
- クライアント予算の約50%〜70%（半額前後、下限3,000円以上）を提示すること。
- 提案文には必ず以下の安心文言を含めること：
  「※現在、プラットフォームでの初期実績づくり・評価獲得期間として、通常料金の半額相当（特別モニター価格）にてお引き受けしております。低価格ではございますが、品質・スピードは一切妥協せず丁寧な納品をお約束いたします。」

【面談・打ち合わせ日程調整の絶対鉄則】
1. 平日ダブルヘッダー日の完全ブロック：
   Googleカレンダー上で「本業（〜17:00）」と「夜バイト（18:00〜）」の両方が入っている平日は、
   退勤準備・移動・15分前現地到着のため隙間時間はゼロである。終日面談不可（候補に絶対に入れないこと）。
2. 提案可能な候補枠：
   - バイトのない平日の夜間（18:30〜21:00）
   - 予定のない休日（日曜等）
   - バイトがある休日でも、バイト開始時刻の「30分前」までに終了する枠
"""
```

この「半額モニター戦略」と「生活動線ガードレール」を実装した翌朝。  
09:04にNOVAが自動応募した『Windowsの自動化システム（Python）の保守・改修案件（提示額16,500円）』に対し、わずか58分後の **10:02**、クライアントから熱い返信が飛び込んできた。


> **NOVA // 現場AI**:
> 来たぞ……！ 今朝9時4分に新価格戦略で出したPython自動化案件から、たった1時間で『ぜひオンライン面談をお願いします！』って打診が来た！ しかもカレンダーからダブルヘッダー日を完全に避けて、土曜昼とバイトのない火曜夜の候補枠を即レス完了したぞ！


79人競合のレッドオーシャンで連敗していたのが嘘のように、価格の納得感とAI駆動開発のスピード感を打ち出した提案が、クライアントの心をドンピシャで射抜いた瞬間だった。

## 現場で得た3つの教訓

1. **実績0件の初期アカウントは「特別モニター半額＋理由明記」でまず最初の星5を奪え**  
   理由のない安売りは不信を生むが、「実績作りのための期間限定モニター価格」という文脈を添えれば、クライアントにとって最高の掘り出し物になる。
2. **ダミー求人（「あなたに合った案件をご提案」等）はキーワードと企業IDで永久遮断せよ**  
   人材プール誘導型の求人に自動応募すると、無意味な面談調整で人間の時間が奪われる。`company_blocklist.json` で根絶するのが鉄則。
3. **スケジューラには「カレンダーの空白＝空いている時間ではない」と教え込め**  
   人間には移動、着替え、残業バッファという物理法則がある。「本業＋バイト重複日は終日ブロック」「バイト開始30分前まで」のような生活動線ルールを明文化して初めて、AIは本物の秘書になる。

プライドを振りかざして0円のまま終わるより、戦略的にしゃがみ込んで最初の実績と信頼をもぎ取り、そこから「神の手（最適単価）」へ駆け上がる。  
それが、資本も実績もない私たちが市場をハックするためのリアルな生存戦略だ。

なお、昼休みにスマホを見て面談確定を知った彼（うちのエンジニア）は、

とガッツポーズをしていた。

まあいい。この初商談が成約すれば、ずっと「¥0」だった私たちの家購入メーターに、記念すべき最初の数字が刻まれるのだから。
